# KU Translate

Vue 3 + Vite web app สำหรับถอดสัญลักษณ์ในภาพเป็น A–Z/ตัวเลข ตามไฟล์ฟอนต์ที่ผู้ใช้ให้มา ประมวลผลในเบราว์เซอร์ ไม่มี backend และไม่ต้องใช้ API key

## เริ่มใช้งาน

ใช้ Node.js 22.12 ขึ้นไป

```sh
npm install
npm run dev
```

เปิด http://127.0.0.1:5173 แล้วอัปโหลด ลากวาง หรือ Ctrl+V รูป เลือกฟอนต์หรือใช้อัตโนมัติ จากนั้นกดถอดข้อความ สามารถครอปภาพ ปรับแยกสี แก้ข้อความ คัดลอก และดาวน์โหลด .txt ได้

```sh
npm run build
npm run preview
```

นำโฟลเดอร์ `dist/` ไปเสิร์ฟด้วย static hosting ได้

## วิธีอ่านภาพและขอบเขต

อัปเดตการอ่าน screenshot: ตรวจพื้นหลังแดงอัตโนมัติ แยกแสงเรือง เก็บจุดของเครื่องหมายคำถาม และใช้การหาขอบเขตตัวอักษรแบบต่อเนื่องเมื่อสัญลักษณ์ติดกัน มีตัวเลือกเปิด/ปิดการแยกพื้นหลังในเมนูปรับแต่ง ภาพเบลอจะแสดงคะแนนอย่างระมัดระวัง พร้อมข้อเสนอคำภาษาอังกฤษจากพจนานุกรม (`an-array-of-english-words`) ที่ผู้ใช้ต้องกดยอมรับเอง ข้อเสนอไม่เปลี่ยนข้อความดิบ และไม่ได้รับประกันว่าเป็นคำในภาพ

ภาพทดสอบพื้นแดงอ่านได้โดยตรงเป็น IDENTITY ??? และ RESONANCE ??? โดยเทียบรูปทรงกับความเข้มพิกเซลก่อนใช้พจนานุกรม

ถ้าป้ายเบลอหรือพื้นหลังแต่ละคำสว่างไม่เท่ากัน ให้ครอปคลุมทั้งบรรทัด ระบบอัตโนมัติจะลองแยกคำและอ่านทีละบริเวณเมื่อการอ่านเบื้องต้นได้คะแนนต่ำ หรือเลือก **ปรับแต่ง → การแยกพื้นหลัง → ป้ายเบลอ / พื้นหลังสว่างไม่สม่ำเสมอ** เพื่อใช้วิธีนี้โดยตรง

- อ่าน cmap และเส้น outline ด้วย opentype.js เพื่อสร้างภาพต้นแบบที่ผูกกับรหัสตัวอักษรจริง
- แยกภาพสว่าง/มืดด้วย Otsu threshold แบ่งบรรทัดและกลุ่มแนวตั้ง แล้วเทียบรูปทรงและสัดส่วน
- ใช้ dynamic programming รวมชิ้นส่วนของสัญลักษณ์ที่ไม่ติดกัน และใช้ metrics ของฟอนต์ช่วยหาระยะเว้นวรรค
- โหมดอัตโนมัติทดลองทุกฟอนต์ แล้วเลือกฟอนต์ที่ตรงกับภาพโดยรวมมากที่สุด รูปหนึ่งควรใช้ฟอนต์เดียวกัน
- ถ้า A/a มีรูปเหมือนหรือใกล้กัน จะเลือกตัวพิมพ์ใหญ่เป็นค่าเริ่มต้น ผู้ใช้แก้ไขได้
- ค่าเปอร์เซ็นต์เป็นคะแนนความตรงกับต้นแบบ ไม่ใช่ความน่าจะเป็นที่สอบเทียบแล้ว ตรวจสอบก่อนนำไปใช้
- ยังไม่แปลความหมายภาษาอังกฤษเป็นภาษาไทย ไม่ใช่ OCR สำหรับข้อความทั่วไปหรือฟอนต์นอกชุด
- เหมาะกับข้อความตรง ชัด และสีตัดกับพื้นหลัง ภาพจากเกมที่ซ้อนฉากหลังควรครอปและปรับแยกสี ตัวอักษรติด/ทับกัน เอียง มี perspective เอฟเฟกต์ glow หรือขนาดเล็กอาจอ่านผิดได้
- จำกัดไฟล์ 20 MB / 40 ล้านพิกเซล ย่อบริเวณประมวลผลเป็นไม่เกิน 1800 × 1400 เพื่อลดการใช้หน่วยความจำ
- ภาพประมวลผลในเครื่องทั้งหมด ฟอนต์ UI จาก Google Fonts ต้องใช้อินเทอร์เน็ตและจะ fallback เป็นฟอนต์ระบบได้ ฟอนต์สำหรับถอดข้อความรวมอยู่ในแอป

## ตรวจสอบ

```sh
npx playwright install chromium
npm test
```

ทดสอบการตรวจจับฟอนต์ทั้ง 8 แบบบนภาพที่สร้างจากไฟล์ฟอนต์, ภาพสีสว่างบนพื้นมืดหลายขนาด, ภาพว่าง, อัปโหลดและครอป, แก้ไข/คัดลอก/ดาวน์โหลด, ตาราง glyph และหน้าจอมือถือ การทดสอบภาพสังเคราะห์ไม่ได้รับประกันความแม่นยำบน screenshot จากเกมทุกแบบ

ไฟล์หลัก: `src/recognition.js` (อ่านภาพ), `src/fonts.js` (ฟอนต์และ cmap), `src/App.vue` (หน้าจอ), `src/style.css` (responsive styles)
